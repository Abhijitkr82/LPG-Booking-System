LPG Booking Management System

📌 Project Overview
LPG Booking Management System is a C++ based console application developed for managing LPG gas booking operations.  
This project is designed as a BCA Final Year Project using Object-Oriented Programming (OOP) concepts.

The system helps manage:
- Customer Records
- LPG Cylinder Booking
- Payment Management
- Stock Management
- User Authentication
- Distributor Details

---

🚀 Features

👤 User Management
- Admin Login
- Operator Login
- Authentication System

👥 Customer Management
- Add Customer
- Update Customer
- Search Customer
- Customer Details

🔥 Cylinder Booking
- New LPG Booking
- Booking Reference Generation
- Subsidy & Market Price Calculation

📦 Stock Management
- Cylinder Stock Tracking
- Low Stock Alert
- Inventory Management

💳 Payment Management
- Payment Records
- Payment Verification
- Invoice Amount Calculation

📊 Reports
- Booking Reports
- Customer Reports
- Stock Reports
