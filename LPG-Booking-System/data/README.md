# Data Directory

This folder stores the runtime `.dat` files generated by LBMS when you run the program.

All 7 data files are auto-created on first run:
- `lbms_users.dat`
- `lbms_customers.dat`
- `lbms_bookings.dat`
- `lbms_stock.dat`
- `lbms_distributors.dat`
- `lbms_payments.dat`
- `lbms_activity.log`
